# Publicación y actualizaciones: plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Ejecución directa autorizada por el usuario; revisión independiente al final.

**Goal:** Entregar un instalador público de Windows que incluya Django y permita detectar futuras actualizaciones firmadas.

**Architecture:** PyInstaller congela el backend; Tauri lo ejecuta junto a sus recursos. GitHub Releases aloja instalador firmado y latest.json. Rust controla descarga e instalación; React muestra disponibilidad y confirmación.

**Tech Stack:** Tauri 2 updater, NSIS, PyInstaller, Django/SQLite, React, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-05-releases-design.md`.

## Global Constraints

- No publicar secretos, bases del usuario ni respaldos.
- Conservar identidad y rutas de datos; actualizaciones por decisión del usuario.
- Respaldo verificado antes de migrar una base existente.
- Documentar todo cambio del backend en API, CAMBIOS y README.

## Review Focus

- Copia fallida no puede permitir migraciones (tarea 1).
- Paquete congelado debe encontrar módulos y migraciones (tarea 1).
- Fallo de descarga no debe detener Django (tarea 2).
- Instalación solo desde Inicio con dueño y sin mutaciones pendientes (tarea 2).
- No publicar una versión ni cambiar visibilidad hasta revisar archivos e historial (tarea 3).
